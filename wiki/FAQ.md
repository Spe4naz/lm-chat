# Частые вопросы

## Как обновить плагин lm-computer?

На компьютере с LM Studio:

```bash
cd ~/lm-computer
git pull
./install.sh
```

Затем перезапустите LM Studio, чтобы он подхватил новую сборку плагина.
Сервис `lm-computer.service` перезапускает сам `install.sh`. Подробная версия
с проверкой и откатом: [lm-computer → Updating](https://github.com/Spe4naz/lm-computer/wiki/Updating).

## Как обновить приложение?

Автоматически — плашка «Доступно обновление» (проверка не чаще раза в 6 часов).
Вручную — скачать APK или установщик из [Releases](https://github.com/Spe4naz/lm-chat/releases).
Полностью: [Updating](https://github.com/Spe4naz/lm-chat/wiki/Updating).

## Почему модель загружается не на 100% GPU?

LM Studio подбирает оффлоад под свободную видеопамять. Часть слоёв остаётся на
CPU — это нормально. Принудительно задать `--gpu max` можно через
[мостик](https://github.com/Spe4naz/lm-chat/wiki/Bridge), но при нехватке VRAM
загрузка может упасть. Оценка: `lms load <модель> --gpu max --estimate-only`.

## Почему ответ обрывается, когда я сворачиваю приложение?

Android замораживает фоновые процессы. Приложение включает foreground-сервис с
wake lock (переключатель **«Продолжать в фоне»**). Если этого мало, включите
«Чат через мостик» — тогда генерация идёт на компьютере и переживает сворачивание,
потерю Wi-Fi и даже убийство процесса. На Xiaomi/Redmi/POCO разрешите
«Без ограничений» и автозапуск.

## Нужен ли мостик?

Нет. Без него чат, история, изображения и статистика работают как обычно.
Мостик нужен для принудительного оффлоада на GPU, оценки памяти и фоновых
заданий. См. [Bridge](https://github.com/Spe4naz/lm-chat/wiki/Bridge).

## Можно ли использовать не LM Studio?

Да. Поддерживаются Ollama и любой OpenAI-совместимый endpoint. Нативный
контекст, TTL и оффлоад — только у LM Studio 0.4+; у остальных работает
стандартный `/v1/chat/completions`.

## Как перенести настройки и историю на другое устройство?

«Настройки → Профиль → Экспорт» для настроек и «Настройки → История →
Экспорт» для чатов. Токены в экспорт не попадают — их нужно ввести заново.
Свой TTF-шрифт остаётся на исходном устройстве.

## Пропали чаты после переустановки. Почему?

История хранится в приватном каталоге приложения. При удалении приложения
Android стирает её вместе с данными. Восстановить можно только из экспорта.
На Windows данные лежат в `%APPDATA%\LM Chat\lm_chat` и при удалении приложения
не удаляются.

## Где хранятся API-токены?

В системном хранилище: Android Keystore, Windows Credential Manager. В JSON
истории, профиле и экспорте их нет. Если системное хранилище недоступно,
токены остаются только в памяти до перезапуска.

## Как открыть доступ снаружи?

Не открывайте порт в интернет. Поставьте Tailscale на компьютер и телефон и
используйте адрес `100.x.y.z` — приложение считает его локальным. Для
публичного endpoint нужен HTTPS: HTTP-адреса вне локальных диапазонов
отклоняются.

## Почему HTTP, а не HTTPS?

LM Studio по умолчанию отдаёт HTTP, а для домашней сети это проще. Трафик при
этом не шифруется: токены и чаты видны в локальной сети. Подробнее — в
[Security](https://github.com/Spe4naz/lm-chat/wiki/Security).

## Почему приложение не подключается к серверу?

Проверьте по порядку:

1. `curl http://<ip>:1234/v1/models` работает с компьютера;
2. в LM Studio включён **Serve on Local Network**;
3. порт открыт в файрволе;
4. телефон в той же сети, без изоляции клиентов на роутере;
5. в адресе нет `/v1`, пробелов и завершающего `/`.

## Как сменить язык, тему и шрифт?

**Настройки → Оформление**. Язык — «Системный», русский или английский; тема —
светлая, тёмная, системная; шрифт — Inter, Manrope или свой TTF; размер текста
90–120%. Плотность интерфейса — обычная или компактная.

## Как посмотреть, что пошло не так?

**Настройки → Диагностика**: последние запросы, ошибки, состояние сервера и
кэша моделей. Лог можно скопировать целиком.

## Приложение много ест памяти?

История и параметры хранятся в JSON и переписываются в isolate. Модель работает
на компьютере, приложение держит только текст чатов и картинки. Если история
большая, экспортируйте и удалите старые чаты.
