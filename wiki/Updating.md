# Обновление приложения

LM Chat обновляется из [GitHub Releases](https://github.com/Spe4naz/lm-chat/releases).
Отдельного магазина приложений нет.

## Автоматически

- При открытии главного экрана приложение проверяет последний релиз, но **не
  чаще одного раза в 6 часов**.
- Проверку можно выключить в **Настройки → Обновления**. По умолчанию она
  включена.
- Если версия новее установленной, появляется плашка «Доступно обновление».
- Кнопка «Позже» запоминает тег этого релиза. Следующий релиз снова покажет
  плашку.

## Вручную

**Android**

1. Скачайте из релиза `lm-chat-universal.apk`.
2. Откройте файл. Android поставит новую версию поверх старой, данные
   сохранятся.
3. Приложение, которое ставит APK из автообновления, попросит разрешение
   «Установка неизвестных приложений» — его нужно выдать один раз.

**Windows**

1. Скачайте `lm-chat-setup-<версия>.exe`.
2. Запустите поверх установленной версии. Настройки и история в профиле
   сохраняются.

## Что проверяется перед установкой

Автообновление не запускает произвольный файл из релиза:

| Проверка | Android | Windows |
|---|---|---|
| Тег новее текущей версии (`version+build`) | да | да |
| Имя файла из белого списка | `lm-chat-universal.apk` | `lm-chat-setup-*.exe` |
| SHA-256 из метаданных GitHub или блока `SHA-256` в описании релиза | да | да |
| Сертификат скачанного APK совпадает с установленным | да | — |
| Authenticode-подпись установщика | — | да |

Если подпись или хеш не совпали, установка отменяется с ошибкой.

## Почему новая версия не предлагается

- В последнем релизе нет файла для вашей платформы (проверьте имена выше).
- Тег равен текущей версии или старше её.
- Вы нажали «Позже» для этого тега.
- GitHub вернул 403 (лимит запросов без токена) или 404 — попробуйте позже.
- Нет сети, или приложение не может достучаться до `api.github.com`
  (корпоративный прокси, блокировка).

Проверить вручную: **Настройки → Обновления → Проверить обновления**.

## Почему обновление не устанавливается

**«Подпись APK не совпадает с установленным приложением».**
APK подписан другим ключом. Android не разрешает обновление через границу
подписи. Варианты:

- взять APK из официального релиза, подписанный тем же ключом;
- удалить приложение и поставить заново — **все чаты на устройстве пропадут**,
  поэтому сначала сделайте экспорт истории и профиля (см.
  [Installation](https://github.com/Spe4naz/lm-chat/wiki/Installation)).

**«Не удалось проверить SHA-256».**
Файл скачался не полностью или в описании релиза нет хеша для этого файла.
Скачайте APK/EXE вручную из релиза.

**«Неподписанный установщик Windows».**
Автообновление запускает только EXE с валидной подписью Authenticode.
Подписанный установщик должен быть собран с `LMCHAT_SIGN_CERT` — см.
[Building](https://github.com/Spe4naz/lm-chat/wiki/Building). Неподписанный
можно поставить вручную, но автообновление его не примет.

**Android не даёт установить APK.**
Разрешите «Установка неизвестных приложений» для LM Chat в системных
настройках.

## Если приложение собрано из исходников

`flutter run --release` и локальные сборки видят ту же версию из
`pubspec.yaml`. Чтобы не получать предложение обновиться на релиз, отключите
автопроверку в настройках или используйте сборку с версией не ниже последнего
тега.

## Плагин lm-computer

Обновляется отдельно, на компьютере с LM Studio:

```bash
cd ~/lm-computer
git pull
./install.sh
```

Подробнее: [Как обновить плагин](https://github.com/Spe4naz/lm-computer/wiki/Updating).
