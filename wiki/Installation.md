# Установка

## Android

Требования: Android 7.0+ (API 24), ~60 МБ на universal APK.

1. Откройте [Releases](https://github.com/Spe4naz/lm-chat/releases) на телефоне.
2. Скачайте `lm-chat-universal.apk` — он подходит для любой архитектуры.
   Компактные варианты (`lm-chat-arm64-v8a.apk` и другие) — только для
   соответствующей архитектуры.
3. Откройте файл и разрешите установку из этого источника, если система
   спросит.

Через ADB:

```bash
adb install -r lm-chat-universal.apk
```

Пакет приложения — `app.lmchat`.

Приложение проверяет сертификат скачанного APK перед автообновлением, поэтому
все APK, которые должны ставиться поверх друг друга, обязаны быть подписаны
одним и тем же ключом. Подробности и предупреждение о debug-подписи — в
[Updating](https://github.com/Spe4naz/lm-chat/wiki/Updating) и
[Building](https://github.com/Spe4naz/lm-chat/wiki/Building).

## Windows

Требования: Windows 10/11 x64.

1. Скачайте `lm-chat-setup-<версия>.exe` из [Releases](https://github.com/Spe4naz/lm-chat/releases).
2. Запустите установщик.

- Устанавливается только для текущего пользователя, без UAC, в
  `%LOCALAPPDATA%\Programs\LM Chat`.
- Ярлык появляется в меню «Пуск», по желанию — на рабочем столе.
- Удаление — через «Приложения и возможности».
- История и токены лежат в профиле пользователя и при удалении приложения не
  удаляются.

Установщик может быть не подписан, тогда SmartScreen покажет предупреждение.
Автообновление запускает только установщик с валидной подписью Authenticode.

Portable-архив `lm-chat-windows-x64.zip` распаковывается вручную; автообновление
его не трогает — новую версию нужно скачивать самому.

## Первый запуск

1. Введите адрес LM Studio: `http://192.168.1.50:1234`.
   Без `/v1`, без пробелов и без завершающего `/`.
2. Если в LM Studio включён **Require Authentication**, вставьте API-токен.
3. Нажмите «Проверить подключение». Приложение запросит `/api/v1/models`
   (или `/v1/models` на старом LM Studio).
4. Выберите модель, при необходимости настройте контекст и оффлоад
   ([LM-Studio](https://github.com/Spe4naz/lm-chat/wiki/LM-Studio)).
5. Напишите первое сообщение.

HTTP разрешён только для локальных адресов: `192.168/16`, `10/8`,
`172.16/12`, `100.64/10` (Tailscale), `localhost`, `.local`. Публичный
адрес по HTTP отклоняется — нужен HTTPS.

## Адрес сервера

Узнать IP компьютера с LM Studio:

```bash
hostname -I
# или
ip -4 addr show | grep inet
```

Если адрес меняется после перезагрузки, закрепите его DHCP-reservation в
роутере или статическим IP в netplan.

Проверка из браузера телефона:
`http://192.168.1.50:1234/v1/models` — должен вернуться JSON со списком
моделей.

## Где хранятся данные

| Что | Android | Windows |
|---|---|---|
| История, чаты, настройки | приватный каталог приложения, `lm_chat_data.json` | `%APPDATA%\LM Chat\lm_chat\lm_chat_data.json` |
| Резервная копия | `lm_chat_data.json.bak` | `lm_chat_data.json.bak` |
| API-токены и токены мостика | Android Keystore | Windows Credential Manager |
| Свой TTF-шрифт | приватный каталог `fonts/` | `%APPDATA%\LM Chat\lm_chat` (каталог `fonts`) |

Токены не попадают ни в экспорт истории, ни в профиль настроек. Если системное
хранилище недоступно, они остаются только в памяти до перезапуска.

## Перенос данных

- **Профиль настроек**: «Настройки → Профиль → Экспорт». Переносятся серверы
  (без токенов), параметры генерации, оформление и свои промпты.
- **История**: «Настройки → История → Экспорт JSON». Импорт — с предпросмотром
  и выбором чатов.
- **Свой шрифт** остаётся на исходном устройстве: в профиль попадает только
  выбор встроенного шрифта.

Перед удалением приложения или переходом на другую подпись сделайте оба
экспорта: после переустановки чаты восстанавливаются только из них.

## Переход со старой версии

Идентификатор приложения — `app.lmchat`. Если вы ставили сборку с другим
идентификатором, Android считает её другим приложением: чаты и токены не
переносятся автоматически. Сделайте экспорт истории и профиля в старой версии,
установите новую и импортируйте. Токены введите заново.
