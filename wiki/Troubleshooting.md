# Устранение неполадок

Сначала откройте **Настройки → Диагностика**: там видно последние запросы,
коды ответов, текст ошибок и состояние сервера.

## «Нет связи с сервером»

| Проверка | Команда / место |
|---|---|
| Сервер отвечает локально | `curl http://127.0.0.1:1234/v1/models` |
| Сервер отвечает по LAN | `curl http://192.168.1.50:1234/v1/models` |
| «Serve on Local Network» включён | LM Studio → Developer |
| Порт открыт | `sudo ufw status`, `ss -ltnp \| grep 1234` |
| Телефон в той же сети | браузер телефона: `http://192.168.1.50:1234/v1/models` |
| Адрес без `/v1` | `http://192.168.1.50:1234` |

Если браузер телефона не открывает `/v1/models`, проблема в сети или LM Studio,
а не в приложении. Частая причина — изоляция клиентов (AP isolation) на роутере
или гостевой Wi-Fi.

Приложение показывает отдельное сообщение, если адрес разрешён, но соединение
заблокировано политикой безопасности (публичный HTTP).

## 401 / 403

- 401 — неверный или отсутствующий API-токен. Включён **Require Authentication**
  в LM Studio? Введите токен в настройках сервера.
- 403 от GitHub при проверке обновлений — временное ограничение запросов.
  Попробуйте позже.

## 404 на `/api/v1/models`

Старое LM Studio без нативных методов. Приложение откатывается к `/v1/models`
и JIT-загрузке; настройки контекста и оффлоада при этом недоступны.

## Ошибка 400 при загрузке модели

LM Studio не принимает поле `gpu`. Приложение само повторяет загрузку без него
и показывает команду для Ubuntu:

```bash
lms load 'имя-модели' --gpu 0.50
```

Скопируйте её и выполните на компьютере с LM Studio.

## Модель не помещается в память

- уменьшите контекст;
- отключите KV-кэш на GPU;
- включите Flash Attention;
- возьмите меньшую модель или более компактное квантование;
- проверьте оценку: `lms load <модель> --gpu max --context-length 8192 --estimate-only`.

## Ответ обрывается

1. Включите **«Продолжать в фоне»**.
2. На Xiaomi/Redmi/POCO: «Без ограничений» для батареи, автозапуск, отключить
   «Не сохранять активности» для разработчиков.
3. Включите «Чат через мостик», чтобы генерация шла на компьютере.
4. После обрыва под ответом появляется «Догрузить ответ».

Если в логе LM Studio есть `Client disconnected. Stopping generation...`, а
сразу за ним `This operation was aborted`, соединение закрыло приложение. До
`1.8.8` это случалось на больших запросах с инструментами: LM Studio молчит,
пока модель формирует вызов, и старый таймаут в 2 минуты обрывал ответ. В
`1.8.9` ожидание увеличено до 10 минут, а активностью считается любой
пришедший байт, поэтому долгий `fs_write` больше не рвётся.

## Мостик не отвечает

- `curl http://<ip>:1235/health` с компьютера;
- `sudo systemctl status lms-gpu-bridge`;
- токен в приложении совпадает с `BRIDGE_TOKEN`;
- порт 1235 открыт в файрволе.

Если мостик вернул ошибку загрузки, приложение не ставит модель через REST
молча — уберите адрес мостика, чтобы вернуться к обычной загрузке.

## Не ставится обновление

- «Подпись APK не совпадает» — APK подписан другим ключом; обновиться поверх
  нельзя, только переустановка с потерей данных (сначала экспорт).
- «Не удалось проверить SHA-256» — скачайте файл вручную из релиза.
- «Неподписанный установщик Windows» — автообновление принимает только EXE с
  валидной подписью Authenticode.
- Плашка не появляется — проверьте «Настройки → Обновления», возможно релиз
  пропущен кнопкой «Позже».

## Голосовой ввод не работает

Ввод использует системный сервис распознавания Android (обычно Google).
Проверьте: разрешение на микрофон, установленный язык распознавания, доступ к
сети (для онлайн-распознавания). На устройствах без офлайн-пакета аудио может
уходить в сервис Google — чаты в LM Studio при этом не пересылаются.

## Не применяется свой шрифт

Импортируются только файлы `.ttf`. Имя файла не должно содержать путь,
`..`, управляющие символы; после импорта шрифт применяется сразу. Если файл
повреждён, приложение вернётся к встроенному шрифту.

## Где взять логи для сообщения об ошибке

«Настройки → Диагностика → Копировать лог». Перед публикацией убедитесь, что в
логе нет токенов и приватных путей, которые вы не хотите раскрывать.
